# Luna Chat Translator — Fabric 1.21.11

自分の画面に表示されるチャットを、各自のCodexログインと `gpt-5.6-luna` で日本語に翻訳するクライアント専用MODです。翻訳結果は本文と置き換えて表示します。サーバーへの導入は不要です。

Minecraftのバージョンに合うものを選んでください。

## 導入

1. Minecraft **Java Edition 1.21.11** に Fabric Loader **0.18.4以降**を導入します。
2. 1.21.11用の **Fabric API** と `luna-chat-translator-1.21.11-0.3.0.jar` を、使用するインスタンスの `mods` フォルダに入れます。旧バージョンのJARは外してください。`-sources.jar` は入れません。
3. 同じPCにCodex CLIをインストールします。WindowsはCodexアプリ付属の `codex.exe` またはnpm版のネイティブ実行ファイルを自動検出します。
4. ゲーム内で **`/lunachat login`** を実行し、開いた公式ログイン画面で各自のアカウントにログインします。
5. **`/lunachat status`** でログイン状態を確認します。

**Mod Menu 17.0.0（1.21.11用）**も導入すると、「Mods → Luna Chat Translator → 設定」から操作できます。Mod Menuがなくても `/lunachat` で同じ画面を開けます。0.1.0からの更新では既存のログインを引き継ぎます。

MODは専用のローカル認証領域を使用します。普段のCodex CLIでログイン済みの場合も、このMOD用に一度ログインしてください。Lunaを利用できるアカウントが必要です。別モデルへの自動変更は行いません。

## 操作

| 初期キー | 機能 |
|---|---|
| **F6** | 選択翻訳を開く。チャットを開いている場合は選択翻訳 ON/OFF |
| **F7** | 新着チャットの自動翻訳 ON/OFF |
| **F8** | すべて原文表示に戻す。自動翻訳もOFF |

チャットを開いてスクロールした状態でもキーを使えます。「設定 → 操作設定 → キー割り当て」のLunaカテゴリで変更できます。チャットを開いた状態で使うキーは、文字入力と干渉しないファンクションキーを推奨します。

チャットを開いて発言にマウスを重ねると、その発言の見えている範囲が青くハイライトされます。**左クリックで複数の発言を選択**できます。選択中は緑色になり、再クリックで解除します。入力欄の上にある **「日本語に翻訳 (件数)」** を押すとまとめて翻訳します。選択・ハイライトだけでは通信しません。1回の依頼は設定の `batchSize` 件までで、それを超える選択は分割します。Shift＋クリックは従来のリンク操作に使えます。選択翻訳は初期状態でONです。

`/lunachat` は操作画面、`/lunachat translate` はクリック選択画面、`/lunachat click` は選択翻訳の切り替えです。`/lunachat toggle`、`/lunachat original`、`/lunachat logout` も使えます。これらはクライアントコマンドで、サーバーへ送信しません。

### 送信前の英訳

チャット入力欄に文を書いて **「入力文を英語に翻訳」** を押すと、英訳を入力欄に戻します。自動送信はしません。内容を確認してからEnterで送信してください。翻訳中に編集した場合やチャットを閉じた場合は上書きしません。空欄・`/`から始まるコマンドは対象外です。入力上限を超えた結果も原文を保持します。英訳も同じ利用枠・使用量集計を使い、同じ文のキャッシュがあればモデルを呼びません。

## EarthMC mode

設定画面または `/lunachat earthmc` でON/OFFできます（初期値OFF）。ONの間、`/vote` を含む発言と、`voted and received a gold crate` などの投票報酬通知を、クリック・自動翻訳の両方から除外します。投票という単語だけの普通の会話は除外しません。モード変更時は処理待ちの翻訳をキャンセルします。

## トークン使用量

**`/lunachat usage`** で、今回のMinecraft起動中の合計・入力・出力・キャッシュ・推論の内訳を確認できます。設定画面にも表示します。

- 計測は今回の起動で最初にCodexへ翻訳を依頼した時からです。キャッシュだけで翻訳した場合は開始しません。
- **起動構成を再起動するとゼロに戻ります。** 同じ起動中のサーバー再接続、F7のON/OFF、ログインし直しではリセットしません。ログイン情報・設定は再起動後も残ります。
- Codexの `thread/tokenUsage/updated` 通知をメモリ内で集計します。**使用量の確認は生成・通信ともに0で、トークンを消費しません。** ディスクへの使用量保存もありません。
- 同じ累計通知を二重計上しません。キャッシュ入力は入力の内数、推論は出力の内数です。
- 失敗・キャンセル・CLIの通知未対応などで数字が届かなかった依頼は「未報告分あり」と表示し、推測で水増ししません。金額やアカウント全体の残量ではなく、このMODが受信した使用量です。
- 0.1.0の過去の利用量は計測できません。

## 応答待ちの改善

手動の翻訳ボタンは500msのまとめ待ちを入れず、自動翻訳の待ち行列より優先します。サーバー参加時にCodex接続を準備し、毎回の認証状態確認を省略します。翻訳が完成した後のCodex後処理も待たずに表示します。Lunaの推論・通信自体の待ち時間は残るため、実測の速度改善量は環境によって変わります。

## 表示と対象範囲

- 翻訳中は原文を表示し、完了後に同じ発言の本文を置き換えます。
- 元のチャット記録・署名・送信処理は変更しません。翻訳の表示には青いLunaインジケータを付け、原文を確認できるようにします。
- 通常の `<プレイヤー名> 本文` では名前を保持します。一般的な `[ランク] <名前>` や `名前: 本文` も対応します。サーバー独自の複雑な書式は、装飾や名前の完全な保持を保証できません。
- 選択した時点で見えていた発言の範囲だけが対象です。画面端の折り返し発言は、見えている部分だけを翻訳し、画面外部分は原文を残します。
- 部分翻訳済みの発言も再送信しません。残りを翻訳したい場合はF8で原文に戻し、表示範囲を変えて再び選択して翻訳ボタンを押してください。
- 文字の順番が描画で入れ替わる言語や他MODの特殊な描画で、部分表示の文字範囲を確定できない場合は、その発言をスキップします。
- F7はON以降の新着のみ対象です。スクロール中などで画面外にある新着、F1でHUDを隠している時の新着、チャット非表示時の新着は送りません。
- チャットを閉じた状態では、通常の表示時間（200 tick）を過ぎた発言を対象外とします。
- 自動翻訳OFFで処理待ちの依頼をキャンセルします。適用済みの訳は残ります。切断時は自動翻訳OFFになり、訳の表示を消去します。翻訳キャッシュは同じ起動中は保持し、F8後の再翻訳にも使います。
- まとめて非同期処理するため描画を待たせません。訳の長さに応じて折り返しを更新し、スクロール中は見ている発言を基準に位置を保ちます。

## 設定

初回起動で `config/luna-chat.json` を作成します。ファイルを手で変更した場合はゲームを再起動してください。操作画面での切り替えは即時反映し、設定も保存します。

```json
{
  "codexExecutable": "codex",
  "model": "gpt-5.6-luna",
  "targetLanguage": "Japanese",
  "timeoutSeconds": 60,
  "batchSize": 12,
  "batchDelayMillis": 500,
  "clickToTranslate": true,
  "earthMcMode": false
}
```

Codexが見つからない場合、`codexExecutable` に `codex.exe` の絶対パスを設定します。JSON内のWindowsパスの `\` は `\\` と記載するか、`/` を使用してください。`.cmd` / `.bat` は直接起動しません。

## 認証・通信

翻訳対象の原文はCodexを経由してOpenAIに送信され、各プレイヤーのCodex利用枠を使います。無制限・即時翻訳を保証するものではありません。スクリーンショットやワールドデータは送信しません。翻訳ボタンがサーバーへ自動送信することはありません。入力文の英訳は、ユーザーが通常のEnterで確定した時だけ送信されます。

ゲームフォルダの **`luna-chat-private` は認証情報を含む個人用フォルダです。共有・配布しないでください。** 認証はCodex app-serverの公式ログイン処理に任せます。普段のCodex設定や認証ファイルをコピーしません。

専用Codex設定ではシェル・ブラウザ・外部アプリ・プラグイン・フック等を無効化し、読み取り専用サンドボックスを使用します。チャットはJSONデータとして渡し、モデル出力もJSONの件数・ID・長さを検証してから表示します。タイムアウトや接続・認証・モデル・利用枠のエラーでは原文を保ち、自動翻訳を停止します。

## ビルド

JDK 21をインストールし、`JAVA_HOME` を設定して実行します。

```powershell
.\gradlew.bat build
```

出力は `build/libs/luna-chat-translator-1.21.11-0.3.0.jar`。macOS/Linuxでは `./gradlew build` です。単体テストは `./gradlew test`、Minecraft内の入力・表示テストは `./gradlew runClientGameTest`。後者はキャッシュを使い、オンライン翻訳を実行しません。開発用クライアントは `./gradlew runClient`。

Windowsで `GradleWorkerMain` が見つからないエラーが出る場合は、プロジェクトと `GRADLE_USER_HOME` を英数字のみのパスに置いて再実行してください。この環境では日本語パスでGradleのテスト用プロセス起動に問題が出たため、英数字パスの検証環境を使用しています。

他のチャット描画改変MODとの互換性、および各サーバー独自の書式は実機で確認してください。オンライン翻訳の検証には、各自のログインが必要です。
